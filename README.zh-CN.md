# 太平天国运动 — HY2206 课堂游戏

[English](README.md) | **简体中文**

适合课堂投屏、两组共同参与的策略游戏。**Classroom v3** 采用简化规则：**1853–1864 共 12 年，每年双方各有 2 次行动**。界面使用英文，地名同时提供英文和中文。

[在线游玩](https://littlecrawler.github.io/hy2206-taiping-game/)

## 离线打开

用 Chrome 或 Edge 打开 **Taiping-Classroom.html** 即可。这个单文件已经包含游戏、两张历史地图、七段音频、双方士兵图标及两张胜利图片。复制这一个文件到课堂电脑就能使用，不需要安装或联网。

根目录的 **index.html** 与它内容一致，用作 GitHub Pages 首页。**dist/** 是便于修改的分文件版本，单独使用时请复制整个文件夹。

## 30 秒讲清规则

1. 太平军先行动，清军随后行动。**每年每队 2 次行动**，由该队所有军队共享。
2. 选择自己的军队，再选择相连城市。**移动**到没有敌军的城市会自动占领；有敌军时选择**进攻**。
3. 战斗比较「兵力 + 一颗六面骰子」，总数大的一方获胜。伤亡和撤退由游戏处理。
4. **1864 年清军回合结束后，城市多的一方获胜**。每座城市 1 分，同分则平局。
5. **北伐奖励：太平军占领北京，立即获胜**。清军占领天京计为一座城市，游戏继续。

每次移动、进攻或增援都消耗 **1 次行动**。两次行动可以由同一支军队使用，也可以分给不同军队。可以点击 **End turn early** 提前结束本队回合，未使用的行动不会保留；两次都用完后点击 **Next team**。点击换队前，仍只有当前阵营可以行动。

没有国库、收入、筑城、单独的占领按钮或强制历史事件选择。历史卡只提供背景，不会锁住游戏。

## 开局与战斗细节

| | 太平军 | 清军 |
| --- | --- | --- |
| 开局城市 | 天京、安庆、合肥 | 北京、江南大营、长沙 |
| 开局兵力 | 6 + 4 = **10** | 5 + 5 + 2 = **12** |
| 增援次数（tokens） | **2** | **3** |

清军在兵力和增援资源上略有优势。其余城市中立。这些是课堂平衡设定，不代表真实历史兵力或精确的领土范围。

- **增援**：消耗 1 次行动和 1 个增援 token，为所选军队增加最多 2 点兵力，单支军队上限 10。Token 不会每年恢复。
- **进攻方获胜**：进攻军队移动到目标城并占领；自身损失 1 点兵力，至少保留 1 点。守军合计损失 2 点并自动撤退。
- **防守方获胜**：进攻军队留在原地，损失 2 点；守军合计损失 1 点，至少保留 1 点。
- **平手**：双方各损失 1 点，城市归属不变。
- 同城多支守军合并计算防守兵力；伤亡优先从最强的军队扣除。
- 撤退自动前往最近的己方城市，不消耗行动，也不受沿途城市归属限制。没有己方城市可撤退时，该军队兵力归零。
- 零兵力军队可以在己方城市通过增援恢复。无法行动时，可换另一支军队，或点击 **End turn early** 提前结束回合。

北伐路线为：天京 → 合肥 → 开封 → 怀庆 → 临清 → 沧州 → 天津 → 北京。每经过一条连接消耗 1 次行动。

## 看懂地图与操作

**红色圆点和地名 = 太平军控制；蓝色 = 清军控制；灰色 = 中立**。士兵头像表示军队当前所在位置，头像上的数字是兵力。军队离开后，城市仍属于原阵营。

红色或蓝色的回合横条在滚动时仍保持可见，明确显示当前行动方和剩余次数。点击 **End turn early** 或 **Next team** 后，才轮到对方行动。

在左侧选择军队，或点击有己方驻军的城市；然后在右侧 **Connected destinations** 中选择目的地。移动或进攻按钮会随目标变化。占领成功时，城市颜色、军队位置、城市分数和占领提示会一起更新。

**Quick rules** 查看简短规则；**Historical atlas** 查看原始地图；年份按钮打开历史卡；**Results** 查看当前比分或最终结果。游戏也保留撤销、全屏、行动日志和文本存档。

## 音频与图片

音效默认**开启**，执行移动或战斗时开始播放。点击声音按钮可以静音。设置 → **Test sound** 可以依次试听行军、战斗、占领音效，不消耗行动。全部音频使用小组提供的七个 MP3 文件，没有合成音效。

| 游戏事件 | 音频 |
| --- | --- |
| 移动 | 行军声，播放 2.5 秒 |
| 战斗 | 刀剑声，播放 3 秒 |
| 占领城市 | City Captured，接在移动或战斗声后 |
| 丢城方下次开始回合 | City Lost，每回合最多一次 |
| 太平军占领北京或按最终分数获胜 | Taiping Victory |
| 清军按最终分数获胜 | Qing Victory |
| 最终同分 | Endgame |

音频不会阻塞游戏。新的移动或战斗会替换之前的播放序列；换队不会打断当前行动与占领音效，丢城提示会接着播放。静音、撤销、恢复存档或新开游戏会停止播放。刷新后声音默认开启，但仅加载页面不会自动播放。

太平军、清军士兵图片显示在地图和军队列表；双方获胜时分别显示小组提供的胜利图片。目前平局使用文字结果。

## 保存与恢复

游戏状态只保存在当前浏览器标签页中，**刷新或关闭网页会清空进度**。

点击设置 → **Save / restore text**，复制存档文字到自己的笔记。继续游戏时粘贴回来，点击 **Restore this text**。存档包含骰子序列，因此撤销后重复同一场战斗，会得到相同点数。

**版本 1、2 的存档使用旧国库规则，无法在 Classroom v3 中恢复，请新开一局**。版本 3 存档会保留该回合剩余的行动数。

## 修改、生成与验证

开发命令需要 Node.js；没有额外依赖。直接打开离线 HTML 不需要 Node.js。

    node preview.mjs

打开终端显示的网址，通常是 http://127.0.0.1:8766。若端口占用，运行 **node preview.mjs 8767**。按 Ctrl+C 停止预览。

修改 **dist/** 文件后，重新生成两个完整 HTML：

    node build-standalone.mjs

运行规则、模拟对局、音频和内嵌素材检查：

    node --test tests/engine.test.cjs tests/sound.test.cjs

测试包含 400 局模拟，检查合法行动、城市归属、行动上限、存档及结束条件。它用于检查程序正确性，不代表真人对局的胜率预测。

| 文件 | 用途 |
| --- | --- |
| dist/index.html、dist/style.css | 页面结构与样式 |
| dist/data.js | 城市、路线、开局军队及历史文字 |
| dist/engine.js | 行动、战斗、回合与存档规则 |
| dist/app.js | 控件、地图更新、弹窗及结果 |
| dist/sound.js | 小组音频的播放 |
| dist/assets/ | 地图、音频与图片 |
| build-standalone.mjs | 把素材打包进两个完整 HTML |
| tests/ | 自动检查 |
| qa/ | 本地验证资料，不提交到 Git |

GitHub Pages 使用根目录的 **index.html**。修改后应同时推送源码和重新生成的 HTML；部署完成后网站才会更新。新版页头显示 **CLASSROOM v3** 和 **Two actions per team each year**。

## 素材与历史背景

- 原始地图和音频保留在项目根目录，网页使用的副本位于 **dist/assets/**。小组提供的四张 PNG 图片位于 **dist/assets/images/**。
- **references/group-proposal-snapshot.txt** 在本地保留早期小组方案；references 文件夹不提交到 Git。Classroom v3 对该方案做了明确的课堂简化。
- 历史文字来自小组研究；页面同时提供 [1864 年外交报告](https://history.state.gov/historicaldocuments/frus1864p3/d433)和 [National Army Museum 关于第二次鸦片战争的材料](https://www.nam.ac.uk/explore/second-china-war)。
- 军队名称代表相关势力，不表示某位领导者本人的实际行军或持续指挥。规则与图片用于课堂展示，不能完整重现历史经验。
- 原始地图的出版信息，以及小组研究的完整参考文献，仍应随课堂展示提供。
